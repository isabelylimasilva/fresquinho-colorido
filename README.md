# 🍓 Fresquinho Colorido

Site de um hortifruti fictício, criado por mim durante o curso de Desenvolvimento de Sistemas.

## O que o site tem
- Menu de navegação com links para cada seção da página
- Catálogo de frutas, verduras e legumes, com imagem e preço
- Seção "Os Mais Vendidos"
- Botão "Adicionar Ao Carrinho" que mostra uma mensagem de confirmação
- Seção "Sobre Nós"

## Tecnologias
- HTML5
- CSS3 (Flexbox)
- JavaScript

## Como rodar
1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` no navegador
